# Web Demo Folder

This folder is the project web demo source code.

It is intentionally kept as `sleep_web_mvp` for now because Windows reported an active file lock when renaming it to `04_web_demo`.

Main entry points:

- `server.py`: current local web server.
- `app.py`: app logic.
- `templates`: HTML templates.
- `src`: frontend/source assets.
- `models`: model files used by the demo.
- `examples`: small example inputs retained for testing.
